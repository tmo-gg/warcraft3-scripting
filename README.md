# TMO.GG Warcraft III Scripting

TMO.GG의 **워크래프트 III 스크립팅 가이드**입니다. Lua로 워크래프트 III 게임 정보를 조회하고 게임 화면에 오버레이를 만드는 방법을 설명합니다.

이 저장소는 워크래프트 III 모듈의 API와 스크립트 예제를 다룹니다. TMO.GG Desktop은 여러 게임을 지원하기 위한 클라이언트이며, 이 가이드의 실행 환경을 제공합니다. 별도의 Lua 설치는 필요하지 않습니다.

## 처음 시작하기

1. TMO.GG Desktop에서 워크래프트 III의 **도구 → 공통 설정 → 스크립트 관리**를 엽니다.
2. 새 Lua 파일을 만들고 `print("Hello, TMO.GG!")`를 입력합니다.
3. **F5**로 실행하고 하단 출력에서 결과를 확인합니다.
4. [시작 가이드](guides/getting-started.md)를 따라 게임 정보를 표시합니다.
