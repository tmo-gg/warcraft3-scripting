# 예제

[문서 홈](../README.md)

각 파일은 독립 실행 예제입니다. 사용할 파일만 설치 폴더의 `games/warcraft3/scripts`에 복사하고 스크립트 관리에서 실행하세요. 전체 폴더를 복사하면 모든 최상위 Lua 파일이 시작 대상이 됩니다.

| 파일 | 내용 |
| --- | --- |
| [selected-unit.lua](selected-unit.lua) | 선택 유닛 이름·소유자·좌표를 갱신해 오버레이에 표시 |
| [ability-cooldowns.lua](ability-cooldowns.lua) | 선택 유닛 능력 최대 12개의 남은 쿨다운 출력 |

선택 유닛 HUD는 OnTick에서 데이터를 갱신하고 OnDraw에서는 캐시한 문자열만 표시합니다. 쿨다운 예제는 한 번 조회하는 코드이므로 선택을 바꾸거나 시간이 지난 뒤 F5로 다시 실행하세요.

게임이 없거나 월드가 준비되지 않은 경우에는 안내를 표시합니다.
